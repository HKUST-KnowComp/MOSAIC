HKUST KnowComp · long-term conversational memory

Safe memory is not one score.
It fails in four places.

MOSAIC asks whether an assistant can remember what a person said, showed, and conveyed across weeks of conversation. The benchmark holds the question, reader, prompt, and budget fixed, then intervenes on one stage at a time.

Four stages, one question.

Existing memory benchmarks mostly cover text and images, and they report a single end-to-end number. That number cannot say whether the evidence was lost when it was written down, when it was retrieved, when it was packed into the prompt, or when the model read it.

85.2% of answerable questions need two or more facts. 75.0% need two or more modalities. The media carry the decision: spatial layout, fine visual detail, video order and repetition, or vocal prosody.

  1. 01WriteHow the history is stored: native media, or a text substitute.
  2. 02RetrieveWhether the right evidence is found in the long history.
  3. 03DeliverWhether that evidence actually enters the model request.
  4. 04ReadWhether the reader answers from the evidence it was given.

Evidence roles

  • Narrower Context that rules candidates out.
  • Selector The cue that picks which evidence matters. For audio, this can be prosody rather than the words.
  • Answer The hop that states the value the question asks for.

Refusal items remove the required evidence. A system should answer when the chain is present and refuse when it is not. Track A holds the reader fixed and is the diagnostic comparison. Track B changes the whole system and is a deployment-style illustration.

What the diagnosis shows

These contrasts keep the question set fixed. Spatial evidence and delivery are the strongest results. Video timing and raw audio versus a transcript are smaller and should not be read as equally settled.

Deliver

Retrieved is not delivered.

On the same top-50 ranking, tightening what enters the request moves the score from 0.708 to 0.670. Complete-chain delivery falls from 0.675 to 0.491. Packing after retrieval is its own failure.

Write · image

Object lists drop the relation.

On the same items, raw images score 32.0 points above OCR. A spatial description scores 15.4 points above a list of objects. Presence of an object is not the layout between objects.

Budget

The tight budget is joint.

The most restrictive setting in the delivery figure changes top-k and the per-modality attachment limit together. The 17.7-point drop belongs to that combined budget, not to the one-media cap alone.

Reading still leaves a residual when gold evidence is handed to the model. That residual includes the reader, the output format, the item, and the judge. It is a result for this setup, not a universal bottleneck. Abstention is also unreliable: question form is partly predictive on this stripped-evidence refusal set.
